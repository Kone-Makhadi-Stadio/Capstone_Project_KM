Part B: Modelling Approach

Objective

The objective of this project is to investigate whether machine learning techniques can be used to predict whether a financial-services customer is likely to complete a desired customer action. The public UCI Bank Marketing dataset is used to build and evaluate the modelling pipeline before the methodology is applied to the proposed STADIOEquities account-activation problem.

The modelling task is a binary classification problem. The target variable y indicates whether a customer subscribed to a term deposit, with two possible classes: yes and no.

Two classification techniques will be implemented and compared:

Logistic Regression
Random Forest Classifier


The two models were selected because they provide diffeling approaches. Logistic Regression provides an interpretable linear baseline, while Random Forest is an ensemble learning method capable of modelling nonlinear relationships and interactions between variables.
