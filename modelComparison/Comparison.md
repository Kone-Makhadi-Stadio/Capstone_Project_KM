# Model Comparison – Logistic Regression vs Random Forest

## 1. Overview

This document compares the performance of the two machine learning models developed for the Bank Marketing dataset:

- **Model 1:** Logistic Regression
- **Model 2:** Random Forest Classifier

Both models were evaluated using the same test dataset and the same performance metrics. A statistical comparison using **McNemar's test** was also conducted to determine whether the difference in classification performance between the two models was statistically significant.

The performance comparison is implemented in:

`ModelComparison/model_comparison.ipynb`

The notebook uses the saved results and predictions generated by the two modelling notebooks.

---

## 2. Models Compared

### Model 1 – Logistic Regression

Logistic Regression was used as the first binary classification model.

The model was implemented in:

`Model1/model1_logistic_regression.ipynb`

### Model 2 – Random Forest

Random Forest was used as the second classification model and provides a nonlinear, tree-based alternative to Logistic Regression.

The model was implemented in:

`Model2/model2_random_forest.ipynb`

---

## 3. Evaluation Metrics

The models were compared using the following performance measures:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix
- McNemar statistical test

Multiple evaluation measures were considered because the target variable is imbalanced. Accuracy alone may therefore not adequately represent performance on the minority subscription class.

## 5. Accuracy Comparison

Logistic Regression achieved an accuracy of **84.58%**, while Random Forest achieved **89.66%**.

Random Forest therefore produced a higher proportion of correct classifications across the complete test dataset.

The difference in accuracy was:

**89.66% − 84.58% = 5.08 percentage points**

However, accuracy should not be interpreted in isolation because the dataset contains considerably more non-subscribers than subscribers.

---

## 6. Precision Comparison

Logistic Regression achieved precision of **41.81%**, while Random Forest achieved **55.23%**.

Random Forest therefore had the higher precision for the positive subscription class.

This indicates that when Random Forest predicted that a customer would subscribe, that prediction was more frequently correct than the corresponding positive predictions produced by Logistic Regression.

The difference in precision was:

**55.23% − 41.81% = 13.42 percentage points**

---

## 7. Recall Comparison

Logistic Regression achieved recall of **81.10%**, compared with **61.34%** for Random Forest.

Logistic Regression therefore identified a larger proportion of the customers who actually subscribed.

The difference in recall was:

**81.10% − 61.34% = 19.76 percentage points**

This is an important difference between the two models.

If the business objective places a high cost on failing to identify a potential subscriber, the higher recall of Logistic Regression may be particularly relevant.

---

## 8. F1-score Comparison

The Logistic Regression model achieved an F1-score of **55.18%**, while Random Forest achieved **58.13%**.

Random Forest therefore achieved a slightly higher balance between precision and recall according to the F1-score.

The difference was:

**58.13% − 55.18% = 2.95 percentage points**

This metric is particularly relevant because it considers both false-positive and false-negative performance rather than focusing only on overall accuracy.

---

## 9. ROC-AUC Comparison

Logistic Regression achieved a ROC-AUC score of **0.9097**, while Random Forest achieved **0.9266**.

Both models therefore demonstrated strong ability to distinguish between the subscription and non-subscription classes across classification thresholds.

Random Forest achieved the higher ROC-AUC value, with a difference of:

**0.9266 − 0.9097 = 0.0169**

## 11. Statistical Comparison

### McNemar Test

In addition to comparing the performance metrics, a **McNemar test** was conducted.

McNemar's test is appropriate for comparing two classification models when both models make predictions on the same observations.

The test evaluates whether the models have the same probability of producing a correct classification.

### Hypotheses

The hypotheses were:

**Null hypothesis (H₀):**

The Logistic Regression and Random Forest models have the same probability of making a correct classification.

**Alternative hypothesis (H₁):**

The Logistic Regression and Random Forest models have different probabilities of making a correct classification.

The significance level was:

**α = 0.05**

### McNemar Test Results

| Statistical Measure | Result |
|---|---:|
| McNemar Test Statistic | 217.3720 |
| p-value | 3.3855 × 10⁻⁴⁹ |
| Significance Level | 0.05 |
| Statistically Significant | Yes |

The resulting p-value is substantially smaller than the significance level of 0.05.

Therefore:

**The null hypothesis is rejected.**

There is statistically significant evidence that the classification performance of Logistic Regression and Random Forest differs on the test observations.

The statistical test therefore supports the conclusion that the observed differences between the models are not simply attributable to random variation in which test observations each model classified correctly.

---

## 12. Overall Comparison

The two models demonstrate different performance characteristics.

Random Forest achieved higher values for:

- Accuracy
- Precision
- F1-score
- ROC-AUC

Logistic Regression achieved higher:

- Recall

Random Forest correctly classified a greater proportion of observations overall and produced considerably fewer false-positive subscription predictions.

Logistic Regression, however, identified a greater proportion of actual subscribers and produced fewer false negatives.

The McNemar test found that the models' classification performance differed significantly on the paired test observations.

Therefore, the choice between the models should also consider the intended business objective and the relative consequences of false positives and false negatives.

For example, if identifying as many potential subscribers as possible is the primary objective, recall becomes particularly important, and the Logistic Regression model's higher recall is relevant.

If reducing false-positive predictions while maintaining higher overall accuracy, precision, F1-score and ROC-AUC is more important, the Random Forest results provide different advantages.

The performance comparison therefore demonstrates that model selection should be based on the operational requirements of the intended application rather than accuracy alone.

---

## 13. Important Modelling Consideration

The Random Forest feature-importance analysis identified `duration` as the most influential feature in that fitted model.

This variable represents the duration of the customer contact.

If the intended application requires predicting customer behaviour before the marketing contact takes place, `duration` would not yet be available when the prediction is made.

Consequently, the reported results represent the performance of the models using the current experimental feature set.

A future experiment could remove `duration` and repeat the training and evaluation process to determine how the models perform under a strictly pre-contact prediction scenario.

This limitation should be considered when interpreting the practical applicability of the reported results.

## 17. Conclusion

The experiment demonstrates that Logistic Regression and Random Forest produce meaningfully different classification behaviour on the Bank Marketing test dataset.

Random Forest achieved higher accuracy, precision, F1-score and ROC-AUC, while Logistic Regression achieved substantially higher recall.

The McNemar test statistic of **217.3720** with a p-value of approximately **3.39 × 10⁻⁴⁹** indicates a statistically significant difference between the models' paired classification outcomes at the 5% significance level.

These findings demonstrate the importance of evaluating classification models using multiple performance measures and considering the practical consequences of different types of classification errors when selecting a model for a business application.
