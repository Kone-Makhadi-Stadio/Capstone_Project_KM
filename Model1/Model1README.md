# Model 1 – Logistic Regression

## 1. Overview

This folder contains the implementation of **Model 1: Logistic Regression** for the Bank Marketing Capstone Project.

The purpose of this model is to predict whether a bank customer will subscribe to the product being offered during a marketing campaign.

The target variable is:

* `0` – Customer does not subscribe
* `1` – Customer subscribes

Logistic Regression was selected as the first classification model because it is a commonly used technique for binary classification and provides a suitable baseline model for comparison with the second machine learning model.

---

## 2. Notebook

The model is implemented in:

**`model1_logistic_regression.ipynb`**

The notebook contains the complete workflow for:

1. Loading the preprocessed training and testing datasets.
2. Checking the target variable.
3. Converting the target classes to binary values.
4. Training the Logistic Regression model.
5. Generating predictions.
6. Calculating model performance metrics.
7. Producing a confusion matrix.
8. Saving the model results.

---

## 3. Input Data

The notebook uses the datasets generated by the preprocessing stage.

The required files are located in the `Preprocessing` folder:

* `X_train_processed.csv`
* `X_test_processed.csv`
* `y_train_processed.csv`
* `y_test_processed.csv`

The training data is used to fit the model, while the testing data is kept separate for evaluating model performance.

---

## 4. Model Technique

### Logistic Regression

Logistic Regression is a supervised machine learning classification technique used to predict the probability of a binary outcome.

For this project, the model predicts whether the customer subscribed to the bank product.

The model uses the following configuration:

```text
C = 1.0
solver = liblinear
max_iter = 1000
class_weight = balanced
random_state = 42
```

### Hyperparameter Explanation

| Hyperparameter |       Value | Purpose                                              |
| -------------- | ----------: | ---------------------------------------------------- |
| `C`            |         1.0 | Controls the strength of regularisation              |
| `solver`       | `liblinear` | Optimisation algorithm used to train the model       |
| `max_iter`     |        1000 | Maximum number of iterations allowed during training |
| `class_weight` |  `balanced` | Adjusts class weights to account for class imbalance |
| `random_state` |          42 | Provides reproducibility where applicable            |

---

## 5. Model Evaluation

The Logistic Regression model is evaluated using several classification metrics.

### Accuracy

Measures the proportion of all predictions that are correct.

### Precision

Measures the proportion of customers predicted as subscribers who actually subscribed.

### Recall

Measures the proportion of actual subscribers that were correctly identified by the model.

### F1-score

Provides a combined measure of precision and recall.

### ROC-AUC

Measures the model's ability to distinguish between the two target classes across different classification thresholds.

### Confusion Matrix

The confusion matrix shows:

* True Negatives
* False Positives
* False Negatives
* True Positives

A visual confusion matrix is also produced in the notebook.
